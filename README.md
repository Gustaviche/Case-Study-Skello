# Case Study — Skello Support Analytics

## Overview

This project is a data analyst case study focused on customer support performance analysis.

The objective was to analyze support conversations, identify operational insights and build dashboards to monitor KPIs.

## Tools & Technologies

- SQL
- Power BI
- DAX
- Data Visualization

## Key Objectives

- Analyze customer support activity
- Track response and resolution metrics
- Identify performance bottlenecks
- Create business-oriented dashboards

## Deliverables

- SQL analysis queries
- KPI dashboards
- Business insights and recommendations

## Skills Demonstrated

- Data cleaning
- KPI analysis
- Dashboard creation
- Business intelligence storytelling
- Analytical thinking
